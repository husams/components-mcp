# Running with uvx

This package is `uvx` compatible, allowing you to run it without installation.

## Quick Start

From the project directory:
```bash
uvx --from . components-mcp
```

## From Built Package

After running `uv build`:
```bash
uvx --from dist/components_mcp-0.1.0-py3-none-any.whl components-mcp
```

## From Git Repository

```bash
uvx --from git+https://github.com/your-org/components-mcp.git components-mcp
```

## With Environment Variables

Set component directory:
```bash
COMPONENT_DIR=/path/to/components uvx --from . components-mcp
```

## How It Works

`uvx` uses the entry point defined in `pyproject.toml`:
```toml
[project.scripts]
components-mcp = "components_mcp.__main__:main"
```

This maps to the `main()` function in `src/components_mcp/__main__.py`.

## Benefits

- No installation required
- Isolated environment
- Always uses correct dependencies
- Perfect for CI/CD and scripts
